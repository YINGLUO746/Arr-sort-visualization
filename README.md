# Arr-sort-visualization
数组算法排序可视化

一个基于 HTML/CSS/JavaScript 实现的数组排序可视化工具，支持自定义排序算法、随机生成数组、自定义数组元素，直观展示排序过程中数组元素的交换和变化。






功能特性


可视化展示：以柱状图形式展示数组元素，排序过程中动态高亮交换的元素

数组操作：


1.数组置零：将所有数组元素置为 0


2.随机数组：生成 9 个 1-100 之间的随机数组成的数组


3.自定义数组：支持自定义数组长度（1-50）和每个元素的值


自定义排序算法：在代码编辑区编写自定义排序逻辑（操作数组名为 arr），程序会可视化执行排序过程

动态效果：排序过程中元素交换有平滑的过渡动画，排序完成后有颜色反馈

快速开始


运行方式:将最新版本的arr.html文件下载到本地，直接用浏览器打开该文件即可运行（无需后端环境）


使用指南


基础操作：


点击「数组置零」：清空当前数组（所有元素变为 0）


点击「随机数组」：生成随机数组并可视化展示


点击「自定义数组」：输入数组长度和元素值，生成自定义数组


自定义排序算法：


在「排序代码区」的文本框中编写排序逻辑（默认提供冒泡排序示例）


确保操作的数组名为 arr（程序内置的数组变量）


点击「执行排序」，程序会可视化执行你编写的排序算法，展示元素交换过程


技术栈

HTML5：页面结构搭建


CSS3：样式美化、过渡动画


JavaScript：核心逻辑（数组操作、排序执行、DOM 动态渲染、Proxy 监听数组变化）


注意事项


1.自定义排序算法中请确保操作的数组名为 arr，否则程序无法识别


2.自定义数组长度限制为 1-50，避免因元素过多导致界面展示异常


3.排序算法编写时请保证语法正确，程序会捕获语法错误并给出提示


4.该程序仅用于前端可视化展示，不涉及后端交互，所有逻辑均在浏览器端执行
