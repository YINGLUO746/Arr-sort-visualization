## 📌 项目介绍
本项目基于 **HTML + CSS + JavaScript** 开发，目前实现了**冒泡排序**的动态可视化演示。
通过柱状图实时展示数组元素的比较与交换过程，帮助初学者直观理解排序算法的执行逻辑。

## ✅ 项目状态
- 状态：⚪ 开发中
- 已实现功能：
  - 随机生成数组并可视化展示
  - 支持自定义数组输入
  - 支持数组一键置零
  - 冒泡排序动态演示动画

## 🛠️ 技术栈
- HTML：页面结构搭建
- CSS：样式美化与动画效果
- JavaScript：排序逻辑实现与可视化渲染

## 📖 使用方法
1. 克隆或下载项目到本地
   ```bash
   git clone https://github.com/YINGLUO746/Arr-sort-visualization.git
基础操作：
点击「数组置零」：清空当前数组（所有元素变为 0）
点击「随机数组」：生成随机数组并可视化展示
点击「自定义数组」：输入数组长度和元素值，生成自定义数组
自定义排序算法：
在「排序代码区」的文本框中编写排序逻辑（默认提供冒泡排序示例）
确保操作的数组名为 arr（程序内置的数组变量）
点击「执行排序」，程序会可视化执行你编写的排序算法，展示元素交换过程
